# 检测能力清单（规划 / 可扩展）

标记：★=高置信（可直接封） ●=中置信（配合其他证据） ○=低置信（仅提示）

## A. 进程层 — 02_进程检测

| 检测项 | 方法 | 置信 | 状态 |
|---|---|---|---|
| 外挂进程名黑名单 | 枚举进程名/产品名，比对规则库（含模糊：CheatEngine/lsass 伪名） | ★ | 待实现 |
| 可疑路径 | 从 Temp/AppData/下载目录/可移动盘 启动的游戏相关进程 | ● | 待实现 |
| 无签名/坏签名进程 | WinVerifyTrust 校验主模块 | ● | 待实现 |
| 命令行特征 | 参数含 `-inject`、`--cheat`、代理 DLL 路径等 | ● | 待实现 |
| 父进程异常 | 游戏进程由 Office/浏览器/脚本宿主 启动（注入启动） | ★ | 待实现 |
| 启动链伪造 | 父 PID 已退出且被复用（PPID 欺骗） | ● | 待实现 |
| 双开/多实例 | 同游戏多进程共存 | ● | 待实现 |
| 调试器附加 | `IsDebuggerPresent` / `NtQueryInformationProcess(ProcessDebugPort)` | ★ | 待实现 |
| 进程保护痕迹 | 进程被设为 PPL / 提权句柄持有 | ● | 待实现 |

## B. 内存层 — 03_内存检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 无模块内存（内存马） | 扫 `MEM_PRIVATE` 的 RX/RWX 页，比对已加载模块区间 | ★ |
| RWX 页 | `VirtualQueryEx` 找 `PAGE_EXECUTE_READWRITE` | ★ |
| 模块路径异常 | 模块不在磁盘 / 路径在 Temp | ★ |
| 模块头被抹除 | PE 头 `MZ`/`PE` 被清零（manual mapping 特征） | ★ |
| 模块哈希比对 | 磁盘文件与内存映像不一致（inline patch） | ★ |
| 特征码扫描 | YARA 规则扫目标进程内存（Aimbot/ESP/透视 字符串与字节） | ● |
| 栈回溯异常 | 线程 RIP 不在任何合法模块内 | ★ |
| Heap 内 shellcode | 可执行堆块 + 高频特征（`MZ`、`PE\0\0`、jmp/call 序列） | ● |

## C. 驱动层 — 04_模块与驱动检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 已加载驱动枚举 | `NtQuerySystemInformation(SystemModuleInformation)` | ★ |
| 驱动签名校验 | 签名者不在微软白名单/无签名 | ★ |
| 已知外挂驱动黑名单 | 哈希 + 文件名（如各类读写内存驱动） | ★ |
| 隐藏驱动 | 遍历 `\Driver` 对象目录 对比已加载列表 | ★ |
| 内核回调注册 | 检测异常 `Ps*NotifyRoutine` 数量（需驱动） | ● |
| 内核 inline hook | 比对 ntoskrnl 代码段与磁盘映像 | ● |
| BYOVD 痕迹 | 加载已知漏洞驱动（如 `*.sys` 白名单滥用的驱动） | ★ |
| 服务注册痕迹 | 近期创建的 `sc create` 服务/驱动项 | ● |

## D. 注入层 — 06_句柄与注入检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 跨进程句柄 | 枚举全系统句柄，找非白名单进程持有游戏进程 `PROCESS_VM_READ/WRITE` | ★ |
| 远程线程 | 线程起始地址不在任何模块内 | ★ |
| APC 注入 | 队列 APC 到游戏线程 | ● |
| 反射 DLL / manual map | 模块链断裂、PE 头异常 | ★ |
| Hook 检测 | IAT/EAT/Inline hook 与磁盘映像比对（pe-sieve 思路） | ★ |
| 输入注入 | `SendInput`/`keybd_event` 来源进程非白名单 | ● |
| 窗口消息注入 | `PostMessage` 模拟点击（需 ETW/钩子） | ○ |

## E. 硬件与外设 — 07_硬件与外设检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 模拟 HID 设备 | 枚举 HID，识别 Arduino/ Teensy/ KMBox 类 VID/PID | ● |
| 键鼠宏 | 输入时间间隔方差过小（<5ms 固定节拍） | ● |
| DMA 设备 | 枚举 PCIe 设备，找 FPGA 板卡 / 未知厂商 ID | ★ |
| 串口/虚拟串口 | 枚举 COM 口，识别外挂通信口 | ● |
| 显示器分屏异常 | 副屏采集卡（ESP 硬件方案） | ○ |
| 摄像头/采集卡 | 枚举视频采集设备 | ○ |

## F. 环境层 — 08_环境与虚拟机检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 虚拟机 | CPUID hypervisor 位、注册表、驱动、MAC 前缀 | ● |
| 沙箱 | 进程数/用户名/磁盘大小/近期快照 | ○ |
| 调试器 | 见 A 层 | ★ |
| 时钟异常 | `QueryPerformanceCounter` 与系统时间偏移（变速齿轮） | ● |
| 句柄表篡改 | 句柄权限与进程对象不符 | ● |

## G. 网络与行为 — 09_网络与行为检测

| 检测项 | 方法 | 置信 |
|---|---|---|
| 外挂进程回连 | 可疑进程的 TCP/UDP 连接目的地 | ● |
| 注入源定位 | 谁把 DLL 写进游戏（ETW/驱动） | ★ |
| 可疑域名/IP | 规则库黑名单 | ● |
| 流量特征 | 固定心跳包 / 加密隧道端口异常 | ○ |

## H. 文件与签名 — 05_文件与签名校验

| 检测项 | 方法 | 置信 |
|---|---|---|
| 数字签名 | `WinVerifyTrust` + 证书链 + 签名时间 | ★ |
| 签名滥用 | 合法签名但哈希不在白名单（盗签） | ★ |
| 查壳 | 区段名/熵值/入口点特征（VMProtect/Themida/UPX） | ● |
| PE 异常 | 时间戳伪造、节表异常、导入表过小 | ● |
| YARA | 全盘/指定目录扫特征 | ● |
| 文件哈希库 | 已知外挂文件 MD5/SHA256 | ★ |

## 实现优先级建议

1. **P0**：A 层进程/父进程、B 层无模块内存+RWX、C 层驱动枚举+签名、D 层跨进程句柄
2. **P1**：注入 hook 检测、YARA 内存扫描、句柄持有链
3. **P2**：硬件外设、网络行为、时钟异常
4. **P3**：内核驱动（回调 + ETW TI）
