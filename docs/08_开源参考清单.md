# 开源参考清单

克隆到 `13_开源参考\github\`，只做**参考阅读与思路借鉴**，正式程序不直接依赖其中闭源/受限代码。

## 一、进程 / 内存取证（最接近"查挂"的内核）

| 项目 | 地址 | 用途 |
|---|---|---|
| pe-sieve | https://github.com/hasherezade/pe-sieve | 扫描进程内注入、hook、模块替换、shellcode，查挂核心参考 |
| hollows_hunter | https://github.com/hasherezade/hollows_hunter | 基于 pe-sieve 全系统扫描可疑进程，可直接当检测内核 |
| moneta | https://github.com/forrest-orr/moneta | 内存威胁检测：私有 RWX、隐藏模块、无模块执行 |
| artifacts-kit | https://github.com/forrest-orr/artifacts-kit | 内存工件库，可嵌入自研扫描器 |
| Patriot | https://github.com/forrest-orr/Patriot | 内存扫描器，断链模块检测 |
| MemProcFS | https://github.com/ufrisk/MemProcFS | 内存文件系统，远程/本机内存分析 |
| volatility3 | https://github.com/volatilityfoundation/volatility3 | 内存镜像分析（离线取证） |
| System Informer | https://github.com/winsiderss/systeminformer | 进程/句柄/线程查看器，句柄枚举实现参考 |
| Process Hacker 插件生态 | 同上 | 内核驱动 KProcessHacker 参考 |

## 二、反调试 / 反虚拟机 / 反沙箱（对抗特征库）

| 项目 | 地址 | 用途 |
|---|---|---|
| al-khaser | https://github.com/LordNoteworthy/al-khaser | 反调试、反VM、反沙箱检测技术大全，反向即检测器清单 |
| pafish | https://github.com/a0rtega/pafish | 沙箱/VM 检测，可当"检测项来源" |
| capa | https://github.com/mandiant/capa | 能力识别规则，可借其规则表达方式 |
| YARA | https://github.com/VirusTotal/yara | 特征规则引擎 |
| yara-python | https://github.com/VirusTotal/yara-python | Python 绑定 |
| Atomic Red Team | https://github.com/redcanaryco/atomic-red-team | 注入/持久化技术用例，正好当自测样本集 |
| Detours | https://github.com/microsoft/Detours | 注入/hook 原理参考（检测对面） |

## 三、驱动与内核

| 项目 | 地址 | 用途 |
|---|---|---|
| Windows-driver-samples | https://github.com/microsoft/Windows-driver-samples | 回调、通知、文件系统过滤示例 |
| Windows Internals 工具集 | https://github.com/zodiacon/WindowsInternals | 系统信息查看工具，NTAPI 用法参考 |
| krabsetw | https://github.com/microsoft/krabsetw | C++ ETW 封装 |
| ETW 事件清单 | https://github.com/jdu2600/Windows10EtwEvents | 找可用 ETW provider/事件 |
| Sysmon 配置 | https://github.com/SwiftOnSecurity/sysmon-config | 进程创建/镜像加载监控配置 |

## 四、PE / 逆向 / 静态分析

| 项目 | 地址 | 用途 |
|---|---|---|

| FLOSS | https://github.com/mandiant/flare-floss | 字符串混淆还原 |

## 六、游戏侧反作弊（商业闭源，仅思路）

- EasyAntiCheat / BattlEye / Vanguard / nProtect：技术栈为**内核驱动 + 签名验证 + 句柄监控 + 心跳**，公开资料可查其专利与逆向分析文章，放 `13_开源参考\papers\`。
- Unity 商业资产 Anti-Cheat Toolkit：https://github.com/codestage/Actk —— 检测内存修改、变速、PlayerPrefs 篡改，纯托管层方案，可参考其思路。
